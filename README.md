# Pesquisa de Opinião - TudoWeb

Projeto desenvolvido como atividade do curso Técnico em Desenvolvimento de Sistemas da Etec.

## Sobre o projeto

O programa realiza uma pesquisa de satisfação sobre o atendimento prestado pela empresa fictícia TudoWeb.

Para cada entrevistado, são solicitados:
- Nome
- Idade
- Opinião sobre o atendimento

As opções disponíveis são:

1 - EXCELENTE  
2 - BOM  
3 - RUIM

O programa utiliza uma estrutura de repetição para realizar a pesquisa com 50 entrevistados e estruturas de decisão para verificar as respostas.

Ao final, são exibidas:
- Quantidade de respostas EXCELENTE
- Quantidade de respostas RUIM

## Teste

Foram realizados testes com 10 entrevistados para verificar o funcionamento do programa.
